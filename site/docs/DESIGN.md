# 视觉与交互设计

已调用 `ui-ux-pro-max`。本轮先检查现有页面与 kiikoread、CrossLink、CrossMux 的真实网站截图，再研读 YanReader、脆皮鸭 CPYOS、VanOS 的公开许可、发行和刷写实现。它们没有统一的法律审批门禁，但各自保留了不同范围的许可、发布哈希、网页刷机和更新机制。可借鉴的是材料公开、固定工具、明确校验和备用分发源，不是照搬整片擦除或不验证 TLS 的做法。

## 本项目选择

- **区分度**：使用深色阅读控制台 `#111b25` 与暖橙行动色 `#f2a65a`，安装区单独采用浅色 `#ece9df`。不再使用第三方网站普遍趋同的白底书香风。
- **文案直接**：首屏改为“小纸 Pico，也能好好读书”，直接说明 TXT/EPUB、传书、字体和续读；删去抽象宣传和多余诗意标签。
- **真实界面**：首屏和独立展示区使用真实固件 UI 代码渲染的 WebP，书籍和正文为合成夹具，不使用真实阅读记录、私人照片或账号。
- **两步安装**：检查与备份 → 写入与校验。步骤随真实状态更新并带 `aria-current="step"`。高级连接选项折叠，不默认让用户选择复位策略。
- **单通道**：网页和设备只提供正式版 stable；preview 仅用于内部签名候选，不在用户设置中展示。
- **可达性**：主源为 GitHub Pages；仅在网络 TypeError 时切换到 jsDelivr `testingcf` 的固定镜像分支。404、取消、地址变化、超长、签名或哈希错误不切换，不改变签名内容。
- **安全不降级**：实物型号、签名、完整 16MiB 备份、SHA 证据、写入授权、四段回读、NVS/storage 保护全部保留；不采用整片擦除或关闭 TLS 验证的第三方做法。
- **可访问性**：原生控件、清晰焦点、44px 级操作区、单一 live 状态区、键盘导航、缩放和 reduced-motion。
