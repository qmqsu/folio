适配支持浏览器可解码的静态 PNG / JPEG / BMP。动画 PNG、GIF、WebP、HEIC / HEIF 不做静态化；不支持转换时可另选原样保存。原样保存不代表能在设备上显示。

格式、上限与设备支持
  • TXT / EPUB 可供阅读；PDF / MOBI / AZW3 仅保存，不能在本机阅读。
  • PNG / JPEG 及 BMP / GIF / WebP / HEIC / HEIF 可原样保存。设备显示仍限符合解码要求的 PNG / JPEG；其他格式不能直接用作壁纸或封面。
  • TXT ≤ 16 MiB；EPUB / PDF / MOBI / AZW3、原样图片各 ≤ 32 MiB；TTF ≤ 6 MiB；folio.bin ≤ 3 MiB；校验文件 ≤ 160 B。适配副本 ≤ 2 MiB。
  • 关机壁纸：原图 ≤ 32 MiB、3200 万像素、最长边 8192；选择时生成屏幕灰度副本，不改原图。支持非交错 8 位静态 PNG、普通 JPEG；大型渐进式 JPEG 请先用上方本地适配。
  • 书籍封面仍限 2 MiB、200 万像素、单边 4096；可用内存仍会影响显示。上传成功不代表满足设备的解码要求。
  • 同名文件不会覆盖。封面放入 books，与书籍同名，例如「山间.txt」与「山间.jpg」。
  • 更新文件仅接受 folio.bin 和 folio.bin.sha256；上传后仍需在设备端确认安装。
