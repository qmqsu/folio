# Folio 原生界面规范

本文保留自早期版本形成的视觉与交互约定；后续页面以当前原生代码和回归预览为准。

这套界面面向小纸 Pico 的 684 × 1216 竖向画布。目标是让书页成为主体，让控制在需要时出现；所有页面由 C 原生绘制，预览直接运行固件的绘制代码。

## 视觉基础

| 项目 | 约定 |
| --- | --- |
| 外边距 | 通常左右 48 px；阅读正文遵循用户页边距设置 |
| 底色 | 纯白；不用渐变、阴影、纸张噪点和大面积灰色背景 |
| 文字 | 主文字黑色，辅助文字深灰 `0x40`；浅灰只作分隔线 |
| 统一模块 | 半径 12 px、2 px 深灰 `0x60` 单层圆角框；白色内部，无阴影；主要模块内距 24 px；书架用留白与细线分组，不逐本包框 |
| 字号层级 | 页面标题 52，区块标题 38–42，主要条目 30–34，说明 24–26 |
| 正文默认值 | 新配置字号 38、行距增加 10、段距 12、边距 48；已有个人设置继续保留 |
| 图标 | 原创统一线性图标；常用视觉尺寸 28–44 px，点击范围独立扩大 |
| 触摸 | 主要控制为 96 px 或更大，约合 8.2 mm；相邻控制通常保留 12–24 px 空隙 |
| 选中状态 | 同一外轮廓改为黑色 3 px 单线，不叠内框；选择项辅以勾选或文字，不只依赖灰阶差异 |
| 居中与对齐 | 按钮用实际字形墨迹边界水平/垂直居中，测量与省略后的绘制文本一致；图标对齐组件中线，正文和连续标签保留基线对齐 |

4.7 英寸、1216 × 684 的标称尺寸对应约 297 ppi。这里的像素指面板像素，不能直接套用手机界面的 44 CSS px / pt 标准。

应用自带 OFL 派生宋体；独立 OFL 资源及 TF TrueType 字体可作扩展。公开回归预览使用项目自带的许可字体，不分发系统字体或用户自备字库。字体资源缺失时临时回退原宋体；具体来源见[字体声明](<../main/assets/fonts/NOTICE.txt>)。

小圆角参考[小纸官方 UI kit](https://github.com/MindReset/read_pico_firmware/tree/main/main/ui)的控件语言；Folio 按最新要求采用 12 px 圆角、单层边框，热力格采用 4 px 圆角。后续新增按钮复用 `panel`、`selected_panel`、`action`，不用双层框或额外套框。底部导航采用独立的无框图标样式；只有有必要区分的模块才画边界。

## 页面与交互

### 首页与根导航

首页、书架、设置共用底部三个固定入口。导航保持 96 px 触区（y=1120–1216），每个入口仍为 180 × 96 px 的独立触区。移除整条外框及选中项小框，仅在 y=1124 放一条浅灰分隔线；44 px 图标的中心为 x=146/342/538、y=1162，保持等距且不显示文字。当前图标用黑色，另两个用深灰，并在当前图标下方 y=1194 放置 24 × 4 px 的短圆角标记。交互 HTML 保留不可见的 `aria-label`；阅读正文和子页面沿用各自的操作区域。

首页左上「页间 Folio」由 44 px 放大至 52 px，按实际墨迹边界垂直居中于 y=88，与右侧两行日期时间形成平衡。右上时间与日期整组右对齐。三个模块对齐同一左右边界：继续阅读 `(48,152,588,288)`，阅读时长 `(48,460,588,252)`，最近阅读 `(48,732,588,372)`，模块间距 20 px。继续阅读左侧为 168 × 240 px 封面，右侧书名最多两行、页码、细进度线与继续操作，整体可点击。最近三本改为三条 540 × 96 px 横排，每条左侧 56 × 84 px 封面，右侧书名与进度、末端箭头，使用轻分隔而不再套小卡片。最近阅读按最后打开顺序去重，只显示已有记录；没有历史时引导去书架。

统计显示今日与累计时长。热力图采用截至今天的连续 28 天，每格一天，按从左到右、从上到下排列，末格为今天；14 列 × 2 行铺满 539 × 71 px 图表区，格子 32 × 32 px、4 px 圆角，横纵间距均为 7 px。不再保留左侧日期、星期轴或颜色图例，不生成未来空格；零阅读日也绘制格子。颜色仍表示积累，精确今日/累计数字在上方，七天逐日数值可切换条形图查看。今天只加重自身边框，不叠另一圈。图表都是静态信息，无动画或连续刷新。缺失书籍、未校准日期、读写失败分别显示明确状态。

首页时钟按分钟变化刷新；自动刷新不会延后空闲锁屏。正文阅读才累计活跃时长，三分钟无交互停止计时；菜单、加载及低功耗期间暂停。未知日期的时长只计累计，不在日历里伪造记录。

### 书架

默认三列两行，每页六本，去掉逐本外卡框。每列 172 px，封面居中为 160 × 240 px，书名与文件类型对齐同一列中线；当前书通过「上次阅读」状态区分。右上角可切换列表，选择会保存在设备设置中。列表只用必要的细线分隔，视图切换与翻页区域分别合并为一个简洁控件。

首页、最近阅读和书架共用真实封面读取与显示：优先读取 EPUB 中声明的 PNG/JPEG 封面，没有内嵌封面时可读取书籍旁同名图片。图像按比例完整显示，透明背景合成白色，转换为面板的 16 灰阶；不拉伸、不裁掉标题。无可用图像时显示书名及「暂无封面」，不以虚构图片冒充原书封面。

左右分页按钮与横向滑动都可翻页，页码显示在书架下方。底部共用三个图标入口。目录、字体与系统设置在需要区分操作时保留单层圆角条目，内容内缩。书籍原始图像保持矩形，不裁掉真实封面的角部内容。

### 阅读

章节名位于顶部，底部保留时间、电量、页码、百分比和细进度线。正文区从 y=124 到 y=1104，不再放常驻翻页按钮。

左右三分之一区域翻页，中间三分之一区域唤出菜单；横向滑动与 KEY1 / KEY3 也可翻页。KEY2 短按开菜单，长按松开手动全刷。页脚时钟只在需要绘制时更新，不为了走秒唤醒屏幕。

菜单保留上方的一段真实正文，下面以六个大触区组织目录、书签、添加/移除书签、进度、排版、字体。回书架和刷新位于次一级区域，底部明确提供继续阅读；点击上方正文或关闭图标也可退出。

### 排版与偏好

设置分为「排版 / 偏好」两个页签，避免九项设置挤在同一页。排版页显示当前字号、行距下的文字样张，点击样张可进入字体选择；数值用大触区减加按钮，对齐用明确的二选一控件。

偏好页管理全刷间隔、空闲锁屏、开机续读和锁屏画面。开关不再使用减加符号。每次调整保存，保存失败会明确提示。

从排版进入字体选择，返回排版；从阅读菜单进入字体选择，返回菜单。普通页面左上返回与 KEY2 的返回行为一致。

### 进度、书签和提示

进度页可轻点刻度定位，也可用 ±1% / ±10% 调整；确认后才离开当前阅读位置。拖动过程不连续刷新。

书签的正文区域用于跳转，右侧独立的删除区域进入确认页，防止误触立即删除。关机、错误、空书架和缺字体状态都使用同一套留白与操作层级。缺字体时仍保留无需外部字库的英文恢复界面。

锁屏使用书名版式或保留当前正文，按用户设置决定。

## 墨水屏刷新

无动画、滚动惯性、阴影浮层或持续闪烁的加载指示。页面布局明显变化时进行全刷；数值调整等小变化走现有差分灰阶刷新。差分刷新按用户设置的页数上限触发一次清理，避免控制页连续操作始终不全刷。耗时加载只绘制一次状态提示。

这些是界面策略，不代替真实面板的波形、残影和温度测试。一般原理可参考 [Microchip ePaper Display Fundamentals](https://developerhelp.microchip.com/xwiki/bin/view/software-tools/mgs/dev-kits/epd-ug/fundamentals/)；具体驱动与时序继续使用小纸 Pico 官方 BSP。

## 实现与检查

- `main/folio_ui.inc`：原生绘制、字号/灰阶和共享命中区域。
- `main/folio_home.inc`：首页、热力图/条形图、统计图选择与根导航。
- `main/folio_activity.[ch]`：活跃阅读计时、每日时长和最近三本持久化。
- `main/book/folio_cover.[ch]`：封面图像解码、等比缩放、灰阶和内存缓存。
- `main/book/folio_epub.[ch]`：按 EPUB 声明读取封面资源，不转换正文。
- `main/app_main.c`：页面状态与触摸/侧键路由。
- `main/folio_gfx.[ch]`：线段、圆形、圆角填充/描边与统一图标；圆角描边向内，无堆分配。
- `main/book/folio_font.[ch]`：前景/背景灰阶混合，多字号缓存，以及实际可见字形边界查询。
- `tools/tests/run_ui_preview.sh`：运行实际 UI、阅读器和字体代码，输出 684 × 1216 PNG；硬件、EPUB准备和设置持久化由测试替身提供。
- `tools/tests/run_gfx_round_tests.sh`：圆角像素对称、边界、半径钳制、描边与填充一致性检查。
- 早期交互原型留在本地，不随公开源码分发；实际固件效果以当前原生代码及其 PNG 预览为准。

验收覆盖封面/列表切换、前后翻页、返回路径、目录/书签跳转与删除确认、进度定位、设置与字体页面往返、最小/最大正文排版、空/错状态及低电关机回归。实机触摸、灰阶对比、刷新残影与耗时仍须在设备上确认。

0.5.2 另检查连续 28 天窗口的周一、周日与跨月边界，确保所有日期都有格子；使用中文、ASCII、空格、缺字与多字号字体核对墨迹边界，再检查按钮文字实际像素是否居中。

## 0.8 实机反馈调整

子页返回为无框箭头，保留 96×96 点击区。书架搜索、封面、列表采用同一外框内的三个纯图标按钮。系统锁屏与关机并排；Wi-Fi 和日期时间独立成页。阅读顶部不显示工具栏，正文顶部边距 48 px；底部时间、电量、居中章节、页码同列。阅读工具弹窗三列两行，按钮宽 180 px、横向间距 16 px，底部两按钮等宽，继续阅读统一左右内边距。传书页显示当前热点名称、密码和访问地址；请求使用随机会话令牌校验，不再沿用早期六位访问码流程。内置原宋体默认可用，独立 OFL 资源及 TF 卡字体作为扩展选择。

输入统一使用 QWERTY：三行字母 10/9/7 键错列，第三行两侧大小写/退格，底行模式/空格/清空；数字符号页保持同一按键定位。验证码采用 1–9、0 的标准数字键盘。Wi-Fi 密码明文分行显示。
